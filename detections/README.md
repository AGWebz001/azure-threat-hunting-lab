# detections

Microsoft Sentinel scheduled analytics rules, defined in Bicep. Each rule graduates
from a hunt in [`../hunts/`](../hunts/) once the query is tuned.

Every rule records: ATT&CK tactic and technique, severity, query frequency and
lookback, entity mappings, and a link to the hunt it came from.
